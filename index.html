PROJECT 01 / FEATURED SINGLE-CELL · STATISTICAL AUDIT
Open repository ↗

One marker, two failure modes — auditing CD20 (MS4A1) in 700 single immune cells

A single-cell marker can read zero for two very different reasons. This project asks which one we are looking at when a B cell shows no CD20.

The question

After clustering a public 700-cell PBMC atlas without using label information, 34 of 95 B cells read zero for MS4A1. Is that technical dropout — or a real biological state?

The test

A binomial capture model predicts ~34.9% zeros from 10 molecules at 10% capture — close to the observed 35.8%, so dropout alone was plausible. The decisive evidence came from the zero cells themselves: they keep CD79A (33/34), have higher UMI counts (4210 vs 3482), and are enriched for the plasmablast marker MZB1 (30/34 vs 21/61).

The conclusion

The CD20-zero B cells are mostly CD20-low plasmablasts, not solely technical dropout — with a minority of genuine dropout still likely.

PROJECT 02 / FEATURED GENOMICS · WORKFLOW ENGINEERING
Open repository ↗

Reproducible GRCh38 VCF filtering and annotation workflow

A Snakemake workflow that takes a called VCF through quality filtering and functional annotation, with the software environment and configuration kept with the code.

What it does

bcftools hard filters split the calls into SNV and indel sets, and Ensembl VEP adds consequence and clinical annotation. Samples and thresholds live in a config file, not in the rule bodies — so the same workflow can be pointed at a different cohort without editing code.

Engineering details

Per-rule Conda environments pin the tool versions, a CITATION.cff records provenance, and GitHub Actions verifies the workflow runs. This is the annotation stage of a larger variant-analysis stack — the raw-read stages are the next extension.
