# Tharun Kumar J — Personal Site

**Live:** https://tharunkumarjayakumar.github.io/My_resume/

A single-page résumé for Tharun Kumar J, built with a custom, self-contained Jekyll/HTML + CSS theme ("genomics dashboard"). No external Jekyll theme, template, or third-party site generator is used.

## What's here

| File | Purpose |
| --- | --- |
| `index.html` | The whole site — hero, skills, experience timeline, education, projects, publication, talks, achievements, contact |
| `assets/css/style.css` | Custom theme: layout, colors, cards, timeline, animations, responsive rules |
| `_config.yml` | Jekyll/Pages settings |
| `logo.jpeg` | Portrait used on the site |

## Sections

Profile · Technical Skills · Experience · Education · Selected Projects · Publication · Conferences &amp; Workshops · Achievements · Contact

## Local preview

```bash
bundle exec jekyll serve
# or just open index.html directly in a browser
```
